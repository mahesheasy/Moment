# Moment Supabase

Remote project: `Moment` (`rqnzwvzziqflgipxiciz`)
Region: `ap-south-1`

## Client credentials

Use the **publishable** key only.

Never place the service-role key in this Flutter app, `env.json`, or git.

Copy `env.json.example` to `env.json` for local runs.

## Migrations

Every schema change must be a migration.

Version 0.1 has no product tables. Auth/profile schema starts in Version 0.3.
