1. Overview

Moment is a private social-memory app. The home-screen Android widget was rebuilt to behave like a smart notification surface — not a photo gallery. It shows the newest unread moment only, advances after viewing, and shows a time-of-day empty state when caught up.

Separately, the Home tab was redesigned as a camera-first screen (live viewfinder, shutter, gallery, flip) with Memories opened by swipe-up and History in a bottom sheet.

Architecture

Supabase (moments, seen_at) → Flutter (selection, read cache, prefs) → Method Channel → Kotlin (queue, images, Glance UI)

2. Smart Unread Widget

The widget must not behave like a gallery. It is a single unread-moment surface.

BehaviorStatusDetails
Show newest unread moment only Working Queue capped at 1 entry (MAX_ENTRIES = 1)
● prefix on unread sender Working FullMomentLayout in Glance widget
Mark read when opened in app Working onMomentViewed → read cache → sync
Advance to next unread after view Working Sync pushes next or clears widget
Empty state when all caught up Working No read-moment fallback
Show read moment without ● Removed Was a bug — intentionally removed

8. What's Working End-to-End

Widget flow (test on device)

  1. Friend sends moment → widget shows it with ● on sender name
  2. Open moment in app → marks read → widget clears or shows next unread
  3. All caught up → time-of-day empty image (morning / afternoon / night)
  4. Tap empty widget → camera opens (moment://camera)
  5. Kill app → FCM or WorkManager still updates widget
  6. Privacy modes render: blur, private, full + reveal chip
  7. Reveal chip → 3-second full photo in WidgetRevealActivity
  8. Customize widget theme/privacy in Settings → Widget

App flow (test on device)

  1. Home tab = live camera + shutter
  2. Swipe up anywhere → Memories overlay
  3. Tap "History" → moment deck bottom sheet
  4. Gallery + flip icons visible on capture bar
  5. Notifications bell (top right) → notifications page
  6. Capture photo → send flow → moment appears for friends

15. User Journey Flows

Flow A — Friend sends you a moment → Widget

Friend captures & sends → Supabase insert + recipient row → FCM / Realtime / WorkManager → Native downloads image → Widget shows ● Sender

Flow B — You view moment → Widget clears

Tap widget photo → App opens moment detail → onMomentViewed + read cache → HomeWidgetSyncService.sync() → Next unread OR empty state

Flow C — All caught up → Empty state

No unseen moments → clearWidget() on native → WidgetEmptyStateImages picks art → Tap → moment://camera

Flow D — Privacy full mode + Reveal

Widget shows blurred photo → Tap "Reveal" chip → WidgetRevealActivity 3s → Does NOT mark read

To mark read: tap the photo area to open moment in app.

Flow E — Home camera screen

Live viewfinder → Shutter / Gallery / Flip → Send to friends

Swipe up → Memories overlay  |  Tap History → moment deck sheet  |  Bell icon → Notifications

16. Flutter ↔ Android Method Channel

Channel: app.moment/widget — implemented in WidgetBridgePlugin.kt

MethodDirectionPurpose
updateWidgetFlutter → NativePush single moment + metadata to widget queue
pushIncomingMomentFlutter → NativeRealtime incoming moment (optimistic)
syncPreferencesFlutter → NativeTheme, privacy, display options
readLocalPreferencesFlutter ← NativeRead cached widget prefs from device
clearWidgetFlutter → NativeClear moment → show empty state
markMomentViewedFlutter → NativeClear display when moment viewed
saveWidgetSyncSessionFlutter → NativePersist Supabase tokens for background sync
clearWidgetSyncSessionFlutter → NativeLogout — stop background sync
isPinWidgetSupportedFlutter ← NativeCheck pin-widget API availability
requestPinWidgetFlutter → NativePin widget to home screen

Background sync (app killed)

WidgetBackgroundSyncWorker.kt + WidgetSyncScheduler.kt

  • Periodic: every 15 minutes via WorkManager (moment_widget_periodic_sync)
  • Backup: one-shot 8 seconds after login (moment_widget_backup_sync)
  • Worker calls WidgetSupabaseSync.sync() — fetches unseen only, clears widget if none
